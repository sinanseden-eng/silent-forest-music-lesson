THE SILENT FOREST — MUSIC & LANGUAGE

Four guided 40-minute lessons: story and persuasion; there was / were,
adjective–noun and verb–adverb patterns; a bridge to Unit 1, printed page 9,
Exercise 6; and an 80–100-word process-writing workshop.

Contents
- dist/: complete static lesson website
- netlify.toml: publish directory set to dist; no build command required

To use with a Git-connected Netlify project, keep this folder layout.
For a manual static upload, the website folder is dist (it contains index.html).

The storybook reader loads the public GitHub source and pictures over the internet.
It is pinned to the checked storybook revision, so the chapter shortcuts stay aligned.
The book remains in the owner's repository; this package contains a reader loader.

Every visit starts in Student view, including when saved work is restored.
Teacher access: tap the invisible 44-pixel area at the bottom-left, below the save area.
The icon, tooltip and hover highlight are hidden; keyboard focus stays visible.
Tap it again or choose Student at the top to hide the guide. Teacher mode lasts
for the current visit only. This is a discreet display toggle, not authentication.
Save progress buttons at the top and bottom of every step save all answers,
completed steps, and the current lesson position in this browser’s local storage.
Progress restores on the same website, device, browser, and browser profile.
Private browsing or clearing website data can remove saved work. Use Print notes
for an additional copy. The lesson does not send student work to a server.

Suggested timing: four 40-minute lessons.
Lesson 1: Story & persuasion — steps 1–2 (5 + 35 minutes).
Lesson 2: Grammar & sound — steps 3–5 (12 + 20 + 8 minutes).
Lesson 3: The future of music — steps 6–7 (10 + 30 minutes).
Lesson 4: Forecast workshop — step 8 (40 minutes).

Lesson 1 reduces written note-taking and prioritises reading and discussion.
Lesson 2 includes the oral Story Scene Reporter task.
Lesson 3 scans all eight page 9 topics but develops two in depth.
Lesson 4 models, plans, drafts, peer-reviews, and revises an 80–100-word forecast.
